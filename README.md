# watchtower-releases
Watchtower alpha releases: the Sparkle appcast (GitHub Pages) and DMG release assets

## Downloads and source availability

This is the public distribution repository for Watchtower. It holds the signed
alpha update feed and public release guidance. Signed, notarized DMGs and their
SHA-256 checksums are attached to the versioned GitHub Releases, not committed to
Git history. Download the DMG to install Watchtower.

The Watchtower application source repository is private. Application source is
not distributed here. GitHub automatically displays “Source code (zip)” and
“Source code (tar.gz)” links for tags; those archives contain this distribution
repository's metadata, not the Watchtower application source.

The website at https://www.deepwelllabs.com/watchtower/releases automatically
follows published alpha releases with uploaded version-matching DMGs. Installed
apps use https://deep-well-labs.github.io/watchtower-releases/appcast-alpha.xml.
These publication surfaces are verified separately for every release. Read the
version's release notes for exact expiration and testing status.
